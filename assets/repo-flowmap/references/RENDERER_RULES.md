## Typed View의 추가 규칙 — 같은 native renderer

아래 기존 값은 legacy에 적용한다. Typed 구조/class/deployment는 기존 buildEdgeRoutes의
혼잡도 포함 C 경로와 32px strand 간격을 재사용한다. Canonical 부모 경계는 바탕/헤더로,
leaf 본문은 회피 장애물로 사용한다. 같은 컬럼 카드 대신 유형별 실루엣/구획/경계를 그린다.
긴 관계 설명은 번호별 설명표에 표시하며 번호는 시간순이 아니다. 시퀀스는 명시 order에 따른
참가자/생명선/메시지와 반복/자기호출이다. 양끝이 같다는 이유로 메시지를 내부 카드로 생략하지 않는다.
실제 text bbox를 export 전에 측정해 마지막 자기호출의 오른쪽 끝을 포함한다.
원래 camera/state/pan/selection/export를 그대로 쓰며 source-bound SVG는 exportSvg() 실행 결과다.
좁은 화면은 1:1과 native 팬을 제공하고, 전체 맞춤 버튼은 개요용이다. Typed 수동 포트 편집과
관련 노드 필터는 꺼두며, legacy의 같은 기능은 그대로 남는다.
Deployment logical-placement는 원래 부모 경계와 논리 요소를 유지하며 경계 머리글을
관계 연결점으로 사용한다. 호스팅 문구를 포함 관계로 바꾸지 않는다. 화면/SVG는
실제 인스턴스 배치가 아님을 명시한다. physical-instances의 타입/경계 제한은 유지한다.
Interaction 조건은 그 메시지의 원문 note 접두어로만 표시하며 alt/opt 프레임을 만들지 않는다.

# 렌더러 규칙

사용자가 화면에서 확인하거나 조작할 수 있는 고정 동작이다.

## 보기와 라우팅

- **전체 지도**: 모든 노드를 유지하고 카드만 피하는 최단 직각 경로를 계산한다.
- **관련 모듈만 보기**: 선택한 플로우의 노드만 배치하고, 앞서 그린 선과의 중첩·교차에
  벌점을 주어 차선을 분리한다.
- 왕복 연결은 같은 선에 포개지지 않도록 반대쪽 외곽 포트를 사용한다.
- 포트는 위·오른쪽·아래·왼쪽 4방향이며 같은 포트의 여러 선은 슬롯으로 분산한다.
- 포트 분산으로 벌어지지 않는 **구간 전체의 겹침**은 가닥 분리로 처리한다. 같은 직선을
  일정 길이 이상 함께 지나는 선들은 6px씩 어긋난 평행 가닥이 되고, 복도 안에서 순서를
  바꾸지 않는다(꼬면 한 선을 끝까지 못 따라간다). 포트에 물린 첫·끝 구간과 사용자가
  직접 지정한 연결은 밀지 않는다.
- 레인으로도 남는 교차는 **덜 중요한 쪽만 반원으로 넘긴다**. 진행(정방향) 선이 기준선이고
  반환·자기호출만 그 위를 넘는다. 둘 다 넘기면 홉의 뜻이 사라진다. 끝점을 공유하는
  접합부(T자)는 교차가 아니므로 넘지 않는다 — 교차는 홉, 연결은 점이다.
- 단계 번호는 카드·선·다른 번호와 겹치지 않는 후보 위치를 선택하며, 상태 표시(X·분기 라벨)도
  피할 대상에 포함한다.

현재 라우팅 값:

| 항목 | 값 |
|---|---:|
| 카드 안전 여백 | 6px |
| 포트 시작 구간 | 10px |
| 꺾임 비용 | 22 |
| 교차 비용 | 120 |
| 완전 중첩 비용 | 선분 길이 × 18 |
| 가닥 간격 | 6px (선 굵기의 약 2배) |
| 가닥 분리 최소 구간 | 26px |
| 홉 반지름 | 9px |

## 단계 의미

- `from === to`는 기본적으로 카드 내부 처리 행이다.
- `kind: "self"` 또는 `recursive: true`만 외부 순환선이다.
- 진행은 녹색, 반환·콜백은 갈색, 내부 처리는 보라색으로 구분한다.
- 동작을 고르면 첫 단계부터 강조한다.
- 이전·다음은 카메라를 이동하지 않고 강조 상태만 바꾼다.
- 전체 보기로 단계 강조를 해제할 수 있다.
- `meta.title`/`meta.subtitle`은 탭·헤더에 반영되고, 생략 시 기본 문구를 유지한다.
- `status: "stale"` 플로우는 목록에 STALE 배지와 흐림 처리, 상세 패널에
  `stale_reason` 경고를 표시한다.

## 선의 상태

`steps[].state`가 있을 때만 나타난다. 값의 뜻과 판정 기준은 [`../SCHEMA.md`](../SCHEMA.md)에 있고,
여기서는 화면에 무엇이 그려지는지만 정한다.

| 값 | 선 | 덧붙는 표시 |
|---|---|---|
| `failover` | 빨간 `5 5` 점선, 불투명도 .5 | 경로 50% 지점에 X |
| `blocked` | 빨간 실선이 62%에서 끊김, 화살촉 없음 | 끊긴 자리에 X + 나머지 구간을 옅은 점선(유령선)으로 |
| `cond` | 호박색 선 | 34% 지점에 `stateLabel` 칩 |

- 죽은 길을 **지우지 않는다.** 무엇이 죽었는지가 같이 보여야 장애도가 읽힌다.
- 상태가 쓰인 동작에서만 캔버스 범례에 해당 줄이 붙는다. 내보낸 SVG는 이 범례를 들고 나간다.
- 단계 목록에도 같은 상태가 칩으로 붙고 번호 테두리 색이 바뀐다.

## 조작·편집

- 읽기와 캔버스 모드 모두 드래그 이동, 휠·핀치 확대/축소가 가능하다.
- 연결 편집에서 선택 단계의 출발·도착 포트를 4방향으로 바꿀 수 있다.
- 내부 처리 행은 외부 포트 편집 대상이 아니다.
- 수동 연결점은 자동 계산보다 우선하며 저장 시 `localStorage`에 보관한다.
- 키보드: `0` 전체, `F` 동작 맞춤, `1` 실제 크기, `←/→` 단계 이동, `Esc` 선택 해제.

## 표현·출력

- 선 흐름 애니메이션은 느리게 재생한다.
- `prefers-reduced-motion`에서는 **그 자리에서 멈추지 않고 대표 프레임 한 장으로 굳힌다.**
  `stroke-dashoffset`을 0으로 못 박아 누가 열어도 같은 순간(대시 주기의 시작)을 보고,
  현재 단계는 실선으로 굳혀 "지금 이 단계"를 움직임 없이 전한다. 나머지 선의 점선은
  종류(진행·반환·자기호출)를 뜻하므로 그대로 두고, 차단·장애의 대시도 그 자체가 표시라 예외다.
- 범례는 지도 왼쪽 아래에 둔다.
- SVG 다운로드는 현재 지도·선택 상태를 한 파일로 만든다.
- 출력 시 카메라 변환과 편집 포트를 제거하고 전체 좌표, 스타일, 배경, 제목을 포함한다.

## 검증 기준

모든 플로우를 전체 지도와 관련 모듈 보기에서 각각 확인한다.

- 카드끼리 겹치지 않음
- 선이 카드 내부를 관통하지 않음
- 화살촉이 카드 뒤에 숨지 않음
- 단계 번호가 카드·다른 번호와 겹치지 않음
- 내부 처리는 행, 외부 단계는 선으로 표현
- 같은 직선을 함께 지나는 선이 겹쳐 한 줄로 보이지 않음
- 남은 교차마다 한쪽에만 홉이 있고, 접합부에는 홉이 없음
- 상태를 쓴 단계의 X·분기 라벨이 단계 번호와 겹치지 않음
- 화살촉 색이 그 선의 색과 같음(검게 칠해지면 실패)
- `prefers-reduced-motion`에서 두 번 열어도 같은 그림이 나옴
- SVG 경계 밖 요소와 브라우저 콘솔 오류 없음
