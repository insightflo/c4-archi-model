## Typed View의 추가 규칙 — 같은 native renderer

아래 기존 값은 legacy에 적용한다. Typed 구조/class/deployment는 기존 buildEdgeRoutes의
혼잡도 포함 C 경로와 32px strand 간격을 재사용한다. Canonical 부모 경계는 바탕/헤더로,
leaf 본문은 회피 장애물로 사용한다. 같은 컬럼 카드 대신 유형별 실루엣/구획/경계를 그린다.
긴 관계 설명은 번호별 설명표에 표시하며 번호는 시간순이 아니다. 시퀀스는 명시 order에 따른
참가자/생명선/메시지와 반복/자기호출이다. 양끝이 같다는 이유로 메시지를 내부 카드로 생략하지 않는다.
실제 text bbox를 export 전에 측정해 마지막 자기호출의 오른쪽 끝을 포함한다.
원래 camera/state/pan/selection/export를 그대로 쓰며 source-bound SVG는 exportSvg() 실행 결과다.
부모 문서 postMessage 프로토콜: `repo-flowmap-camera`(in/out/fit/one, viewId 일치),
`repo-flowmap-playback`(stop만 있다 — 자동 재개 금지), `repo-flowmap-step`(viewId·stepIndex — 보고서
안내 재생이 단계를 지시하면 렌더러 자체 재생을 먼저 조용히 정리하고 setStep을 적용한 뒤
`repo-flowmap-step-ack`(viewId·requestId·stepIndex·ready·step)로 반영 결과를 알린다. 이
메시지는 재생을 시작하지 않는다 — 단계 지시일 뿐이고 'start' 같은 자동 재개 수단은 없다).
내부 펼치기(A5) 상태 교환: 렌더러는 노드 선택이 바뀔 때마다, 카메라가 확정된 뒤(드래그·
줌 중에는 180ms 묶음) `repo-flowmap-state`(viewId·selectedId·camera{k,tx,ty})를 부모에게
알린다. 부모의 `repo-flowmap-focus`(viewId·canonicalId·camera)는 떠날 때 저장한 선택·카메라를
되돌리는 지시다 — canonicalId가 null이면 '선택 없음'으로 되돌리고, 등록된 노드 ID만 선택한다
(없는 ID로 선택을 지어내지 않는다). 카메라 값은 유한수일 때만 정확한 변환(moveTo)으로
적용하고, 이 지시 역시 재생을 시작하지 않는다.
공유 시각 프로필(D5): 부모의 `repo-flowmap-profile`(roles:{light:{역할:값},dark:{…}})이
색·글꼴·간격 역할 값을 테마별로 덮어쓴다. 역할 ID는 이 템플릿의 기존 CSS 변수명 그대로고,
정의되지 않은 역할은 무시하며(미래 호환) 값은 실제 색·글꼴·간격 값만 허용한다. 기존
light/dark 테마 전환과 직교한다 — 테마를 바꾸면 새 테마의 프로필 값을 다시 적용한다.
이 메시지는 재생·카메라·선택 상태를 건드리지 않고, 빈 맵은 기본 복귀(덮어쓰기 해제)다.
활성 프로필의 역할 값은 SVG 내보내기에도 실린다(기본 프로필이면 내보내기 바이트 무변경).
구조계 뷰(path.c4-edge)의 활성 단계에는 원본 선 위에 작은 진행 표시(`g.c4-flow-mark`, 같은
경로의 오버레이 조각 + 정적 방향 화살촉)를 얹는다. 원본 선의 색·굵기·의존/실현 점선은 그대로
두고, 조각이 출발 → 도착으로 흐른다(키네임 c4-flow-dash·pathLength=100·dasharray 7 93).
상태색은 flowmap 스키마의 `steps[].state`(failover·blocked·cond)가 기록되었을 때만 바뀐다
(failover·blocked=빨강, cond=호박색; blocked는 기존 62% 절단 비유(BLOCK_CUT)대로 그 근처까지
간다). 표준 projection은 구조계 뷰에 이 필드를 만들지 않으므로 기본색이 보통이고, 재시도 같은
기록 없는 의미는 만들지 않는다. 진행 표시는 시각 보조 표시라 aria-hidden이고, 시퀀스 뷰
(이미 번호·활선 강조가 있음)에는 두지 않는다. 내보내기(SVG)에서는 이 표시를 제거하고 기존
선만 남긴다. `prefers-reduced-motion`에서는 조각이 화살촉과 겹치는 대표 위치(58%·차단 45%)에
멈춰 누구에게나 같은 한 장의 정적 방향 표시가 된다.
좁은 화면은 1:1과 native 팬을 제공하고, 전체 맞춤 버튼은 개요용이다. Typed 수동 포트 편집과
관련 노드 필터는 꺼두며, legacy의 같은 기능은 그대로 남는다.
Deployment logical-placement는 원래 부모 경계와 논리 요소를 유지하며 경계 머리글을
관계 연결점으로 사용한다. 호스팅 문구를 포함 관계로 바꾸지 않는다. 화면/SVG는
실제 인스턴스 배치가 아님을 명시한다. physical-instances의 타입/경계 제한은 유지한다.
Interaction 조건은 그 메시지의 원문 note 접두어로만 표시하며 alt/opt 프레임을 만들지 않는다.

### 엣지 앵커 계약 — drawio 원칙을 참고한 독립 구현 (2026-09-16)

외부 코드를 복사하지 않고, 면 위 연결점과 양끝의 바깥 방향 구간을 기존 라우터에 적용했다.
mxPerimeter/OrthConnector와 동일한 알고리즘을 이식했다는 의미는 아니다.

- 단일 연결은 두 단자 중심의 중점을 면 위에 투영한다. 여러 연결은 상대 노드 위치와
  무관하게 면 전체의 고유 슬롯을 사용하여 끝에서 연결점이 합쳐지지 않게 한다.
- 첫 구간은 출발 면의 바깥 방향으로 나가고, 마지막 구간은 도착 면의 바깥쪽에서 들어온다.
  가닥 분산 후 방향·직각·카드 충돌을 검사하고, 위반하면 검증된 분산 전 경로를 유지한다.
- 가까운 카드에서는 여유 공간과 끝 구간 길이를 줄여 직각 경로를 찾는다. 자기 연결도
  같은 경로 탐색을 사용한다. 양끝 방향을 무시하는 Z자 대체 경로는 사용하지 않는다.
- 안전한 경로가 없으면 선을 억지로 그리지 않고 관계 ID를 포함한 경고를 화면과 SVG에
  표시한다. 관계 설명표는 유지한다. 안전을 위해 분산을 취소하면 선이 겹칠 수 있다.
- 관계 번호를 선 위에 안전하게 놓을 공간이 없으면 그림 전체를 지우지 않는다. 번호를
  관계 설명 목록으로 옮기고 그 사유·관계 ID·양 끝 요소 ID를 표시한다. 선의 툴팁과 접근성
  이름에도 번호와 관계 ID를 유지한다. 화면 선택과 SVG 내보내기에 동일하게 적용한다.
- 비-C4 연결점·경로 동작은 유지한다. 선 두께와 화살촉 전체의 충돌까지 보장하지는 않는다.

### 내보내기 범위 재측정 — 숨은 초기화 폴백 (2026-09-16)

- 숨은 iframe 문서에서는 첫 bbox가 0×0이거나 이전 값으로 읽힌다. 초기 렌더, ResizeObserver,
  SVG 내보내기 직전에 실제 도형 bbox를 다시 측정해 기존 범위에서 확장만 한다. 측정은 경로를
  다시 계산하지 않고 관찰 대상 stage 크기를 바꾸지 않는다.
- 도형이 top/left 캔버스를 벗어나면 여전히 오류이다. 숨은 상태에서 초기화한 뒤 패널을 드러내 내보낸 SVG와
  처음부터 보이는 새 다이얼로그에서 내보낸 SVG가 동일해야 한다.

# 렌더러 규칙

사용자가 화면에서 확인하거나 조작할 수 있는 고정 동작이다.

## 보기와 라우팅

- **전체 지도**: 모든 노드를 유지하고 카드만 피하는 최단 직각 경로를 계산한다.
- **관련 모듈만 보기**: 선택한 플로우의 노드만 배치하고, 앞서 그린 선과의 중첩·교차에
  벌점을 주어 차선을 분리한다.
- 왕복 연결은 같은 선에 포개지지 않도록 반대쪽 외곽 포트를 사용한다.
- 포트는 위·오른쪽·아래·왼쪽 4방향이며 같은 포트의 여러 선은 슬롯으로 분산한다.
- 포트 분산으로 벌어지지 않는 **구간 전체의 겹침**은 가닥 분리로 처리한다. 같은 직선을
  일정 길이 이상 함께 지나는 선들은 6px씩 어긋난 평행 가닥이 되고, 복도 안에서 순서를
  바꾸지 않는다(꼬면 한 선을 끝까지 못 따라간다). 포트에 물린 첫·끝 구간과 사용자가
  직접 지정한 연결은 밀지 않는다.
- 레인으로도 남는 교차는 **덜 중요한 쪽만 반원으로 넘긴다**. 진행(정방향) 선이 기준선이고
  반환·자기호출만 그 위를 넘는다. 둘 다 넘기면 홉의 뜻이 사라진다. 끝점을 공유하는
  접합부(T자)는 교차가 아니므로 넘지 않는다 — 교차는 홉, 연결은 점이다.
- 단계 번호는 카드·선·다른 번호와 겹치지 않는 후보 위치를 선택하며, 상태 표시(X·분기 라벨)도
  피할 대상에 포함한다.

현재 라우팅 값:

| 항목 | 값 |
|---|---:|
| 카드 안전 여백 | 6px |
| 포트 시작 구간 | 10px |
| 꺾임 비용 | 22 |
| 교차 비용 | 120 |
| 완전 중첩 비용 | 선분 길이 × 18 |
| 가닥 간격 | 6px (선 굵기의 약 2배) |
| 가닥 분리 최소 구간 | 26px |
| 홉 반지름 | 9px |

## 단계 의미

- `from === to`는 기본적으로 카드 내부 처리 행이다.
- `kind: "self"` 또는 `recursive: true`만 외부 순환선이다.
- 진행은 녹색, 반환·콜백은 갈색, 내부 처리는 보라색으로 구분한다.
- 동작을 고르면 첫 단계부터 강조한다.
- 이전·다음은 카메라를 이동하지 않고 강조 상태만 바꾼다.
- 전체 보기로 단계 강조를 해제할 수 있다.
- `meta.title`/`meta.subtitle`은 탭·헤더에 반영되고, 생략 시 기본 문구를 유지한다.
- `status: "stale"` 플로우는 목록에 STALE 배지와 흐림 처리, 상세 패널에
  `stale_reason` 경고를 표시한다.

## 선의 상태

`steps[].state`가 있을 때만 나타난다. 값의 뜻과 판정 기준은 [`../SCHEMA.md`](../SCHEMA.md)에 있고,
여기서는 화면에 무엇이 그려지는지만 정한다.

| 값 | 선 | 덧붙는 표시 |
|---|---|---|
| `failover` | 빨간 `5 5` 점선, 불투명도 .5 | 경로 50% 지점에 X |
| `blocked` | 빨간 실선이 62%에서 끊김, 화살촉 없음 | 끊긴 자리에 X + 나머지 구간을 옅은 점선(유령선)으로 |
| `cond` | 호박색 선 | 34% 지점에 `stateLabel` 칩 |

- 죽은 길을 **지우지 않는다.** 무엇이 죽었는지가 같이 보여야 장애도가 읽힌다.
- 상태가 쓰인 동작에서만 캔버스 범례에 해당 줄이 붙는다. 내보낸 SVG는 이 범례를 들고 나간다.
- 단계 목록에도 같은 상태가 칩으로 붙고 번호 테두리 색이 바뀐다.

## 조작·편집

- 읽기와 캔버스 모드 모두 드래그 이동, 휠·핀치 확대/축소가 가능하다.
- 조작 안내 문구는 입력 장치를 따라간다(A8): 주 포인터가 coarse(터치)면 터치
  문구만 보여주고 마우스/휠·hover·키보드 전용 문구는 감춘다. 마우스 환경에서는
  마우스+키보드 문구를 보여준다. 실제 키보드 입력이 들어오면 터치 모드에서도
  키보드 안내를 다시 보여준다. matchMedia 변경 때마다 문구가 갱신된다.
  조작 기능 자체(팬·핀치·휠·탭·키보드)는 전 장치에서 동일하다.
- 연결 편집에서 선택 단계의 출발·도착 포트를 4방향으로 바꿀 수 있다.
- 내부 처리 행은 외부 포트 편집 대상이 아니다.
- 수동 연결점은 자동 계산보다 우선하며 저장 시 `localStorage`에 보관한다.
- 키보드: `0` 전체, `F` 동작 맞춤, `1` 실제 크기, `←/→` 단계 이동, `Esc` 선택 해제.

## 표현·출력

- 선 흐름 애니메이션은 느리게 재생한다.
- ▶ 순서 재생은 화면에 보일 때만 진행한다. 탭/임베드 숨김(visibilitychange), 그림 화면 밖
  (IntersectionObserver 선택 API), 문서 제거(pagehide), 전체 화면 닫힘(repo-flowmap-playback:
  stop)에서 정지하고 사유를 패널에 안내한다. 어떤 경로에서도 자동 재개하지 않는다 — 사용자가
  재생 버튼으로 다시 시작하고 지난 시간을 한꺼번에 진행하지 않는다.
- `prefers-reduced-motion`에서는 **그 자리에서 멈추지 않고 대표 프레임 한 장으로 굳힌다.**
  `stroke-dashoffset`을 0으로 못 박아 누가 열어도 같은 순간(대시 주기의 시작)을 보고,
  현재 단계는 실선으로 굳혀 "지금 이 단계"를 움직임 없이 전한다. 나머지 선의 점선은
  종류(진행·반환·자기호출)를 뜻하므로 그대로 두고, 차단·장애의 대시도 그 자체가 표시라 예외다.
  재생 버튼은 이 설정에서 자동 진행을 시작하지 않고 수동 단계 이동 안내로 대체하며,
  재생 중 설정이 켜지면 즉시 정지한다.
- 범례는 지도 왼쪽 아래에 둔다.
- SVG 다운로드는 현재 지도·선택 상태를 한 파일로 만든다. 단, 진행 표시(A4 오버레이)처럼
  움직임으로만 의미가 있는 화면 전용 요소는 클론에서 제거해 정적 저장에는 기존 관계선만
  남긴다. 단계 강조(hot)는 한 장으로도 읽히는 정적 스타일이므로 기존 동작을 유지한다.
- 화면 지도와 내보낸 SVG는 SVG 첫 자식 `<title id>`/`<desc id>`와 루트 `aria-labelledby`로
  이름·설명을 제공한다. ID는 `rfm-<sanitize(viewId 또는 동작 ID|all)>-title/-desc`이며 원본
  ID(점 포함)는 데이터로 보존한다. 내보낸 SVG는 `role="img"`이고 문장은 View의
  question·description(legacy는 동작 summary)로 구성하며, 비면 기본 문구로 떨어진다.
  export 시 이 구조를 `validate_svg_accessibility`가 검사한다.
- 출력 시 카메라 변환과 편집 포트를 제거하고 전체 좌표, 스타일, 배경, 제목을 포함한다.

## 검증 기준

모든 플로우를 전체 지도와 관련 모듈 보기에서 각각 확인한다.

- 카드끼리 겹치지 않음
- 선이 카드 내부를 관통하지 않음
- 화살촉이 카드 뒤에 숨지 않음
- 단계 번호가 카드·다른 번호와 겹치지 않음
- 내부 처리는 행, 외부 단계는 선으로 표현
- 같은 직선을 함께 지나는 선이 겹쳐 한 줄로 보이지 않음
- 남은 교차마다 한쪽에만 홉이 있고, 접합부에는 홉이 없음
- 상태를 쓴 단계의 X·분기 라벨이 단계 번호와 겹치지 않음
- 화살촉 색이 그 선의 색과 같음(검게 칠해지면 실패)
- `prefers-reduced-motion`에서 두 번 열어도 같은 그림이 나옴
- SVG 경계 밖 요소와 브라우저 콘솔 오류 없음
