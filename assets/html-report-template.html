Understand

먼저 알아야 할 것

그림보다 문제, 범위, 한 문장 구조를 먼저 확인합니다.

C4 Views

아키텍처 다이어그램

같은 시스템을 서로 다른 확대 수준으로 나누어 봅니다.

    Dynamic Scenarios

    핵심 실행 흐름

    정상, 실패, 복구 흐름을 시나리오별로 분리합니다.

    Architecture Elements

    구성요소와 책임

    Canonical model의 사실을 재사용하고, 설명 카드에는 이해를 돕는 표현만 추가합니다.

    Audience Explanation

    독자 수준에 맞춘 설명

    사실은 같고, 설명 순서와 용어 밀도만 달라집니다.

    Architecture Review

    장점, 비용, 위험

    근거 Claim이나 Coverage issue에 연결된 해석만 표시합니다.

    Change Review

    변경 전후 아키텍처 비교

    두 시점의 canonical model을 ID 기준으로 견줘 추가·삭제·이동·관계 변경을 표로 모두 남깁니다. 그림은 보조이고 표가 완전한 목록입니다.

    Coverage Boundaries

    확인 필요와 다음 확인

    무엇을 모르는지, 왜 중요한지, 다음에 무엇을 확인할지를 분리합니다.

    Glossary

    용어 정리

    처음 보는 독자가 구조를 따라갈 수 있도록 핵심 용어를 풉니다.

    Evidence & Traceability

    근거와 추적성

    Source Snapshot과 Claim이 어떤 요소, 관계, View에 사용되었는지 확인합니다.

    Validation

    검증과 이해도 Gate

    기술 무결성과 분석 완료 범위를 별도로 표시합니다. 초록 체크 한 개로 모든 죄를 씻는 관행은 여기서 금지합니다.

    Raw Artifacts

    원본 모델과 소스

    평소에는 접어 두고, 수정·diff·재검증이 필요할 때 확인합니다.
