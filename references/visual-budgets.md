# C4 Visual Budgets

시각 예산은 절대 제한이 아니라 첫 화면이 인간의 작업 기억을 짓밟기 시작하는 경고선이다.
초과하면 같은 추상화 수준의 View를 나누거나 확대 경로를 제공한다.

밀도를 화면 설명만 줄여 대응할 때는 작성 세션의 `presentationDetail`(full/labels/minimal,
D2)을 쓴다. 이 값은 모델 범위와 별개 축이며 요소·관계를 줄이지 않고 라벨·설명 표현만
조절한다. 축약 내역은 flowmap의 `c4.presentationLog`에 원본 수·표시 수·변경 이유로 남고
(D6), 경고선을 넘은 View는 view-split-proposal 항목으로 분리를 권장한다. 글자 축소로
밀도를 해결하지 않는다는 아래 원칙과 같은 방향이다.

| View | 기본 경고선 | 대응 |
|---|---:|---|
| System Context | 대상 시스템 포함 약 10개 요소 | 외부 그룹 분리 또는 Landscape 추가 |
| Container | 약 14개 요소 | 도메인·흐름별 Container View 분리 |
| Component | 한 Container, Component 약 15개 | 책임 영역별 Component View 분리 |
| Dynamic | 2~15 step, 핵심 읽기는 5~12 권장 | 정상·실패·재처리 흐름 분리 |
| Deployment | 환경별 View, 중첩 Node 3단계 권장 | Production/Staging 분리 |

## Progressive disclosure

```text
System Landscape
→ System Context
→ Container
→ 선택한 Component
→ 핵심 Code 또는 Deployment
```

각 View에 다음을 표시한다.

```text
이 View가 답하는 질문
의도적으로 보여주지 않는 것
다음으로 확대할 View
```

## 출력 용도별 규격

같은 C4 그림을 문서·발표·인쇄로 옮길 때 글자를 줄여 맞추지 않는다. 밀도가 문제면
같은 추상화 수준에서 View를 나누고, 상세는 확대 경로(다음 View)로 연결한다.
아래 수치는 절대 기준이 아니라 네이티브 렌더러(repo-flowmap 포크)의 현재 실측에서
온 권장선이다. 외부 저장소의 픽셀값을 그대로 강제하지 않는다.

렌더러 실측 기준값:

- 글자 단계: 제목 16–22px(페이지 22 · 카드 17 · 경계 16) / 본문 14px(설명·멤버·
  시퀀스 라벨·관계 행) / 보조 11–13px(종류 12 · 식별자 11 · 기술 12 · 대상 13 · 머리글 13)
- 글자 크기 하한: 11px(식별자·관계 행 ID). 이 아래로 내리는 변경을 하지 않는다.
- 최소 캔버스: 구조 계열 폭 860px, 시퀀스 폭 900px. 내보낸 SVG는 콘텐츠 전체를
  viewBox 안에 담고 좌·우 40px, 위 약 17px, 아래 32px(하한 보장) 이상의 여백을 둔다
  (6개 표준 뷰 실측: 좌 40–48 · 상 16.8–17.2 · 우 40–49 · 하 50–62px).

| 용도 | 권장 캔버스·비율 | 이식 규칙 | 안전 여백 |
|---|---|---|---|
| 문서용 HTML 보고서 | 논리 캔버스 그대로(임베드 영역 폭 ≥ 900px 권장), 세로 스크롤 | 1:1 임베드, 축소 금지. 세부는 브라우저 확대·전체화면으로 확인 | 캔버스 내부 여백은 렌더러 기본값 사용 |
| 발표용 슬라이드 | 16:9(1280×720 또는 1920×1080) | 한 장에 안 들어가면 View 분리, 상세는 확대 View로 연결. 글자 축소로 해결하지 않는다 | 슬라이드 가장자리에서 12px(720p 기준) 이상 |
| 인쇄용 A4 | 세로 210×297mm, 넓은 그림은 가로 | 인쇄 후 최소 글자 ≥ 5pt 확인(공식 아래). 미달이면 View 분리 또는 가로 지정 | 용지 가장자리 15mm 이상(절단 여유) |

인쇄 최소 글자 확인: `최종 pt = 11 × (인쇄 콘텐츠 폭 mm ÷ viewBox 폭 px) × 2.835`다.
예: viewBox 폭 1000px를 A4 세로 콘텐츠 폭 180mm에 인쇄하면 최소 글자 11px ≈ 5.6pt(통과),
viewBox 폭 1600px이면 ≈ 3.5pt(미달 → View 분리 또는 가로 인쇄).

이식 원칙(공통):

- 같은 그림을 슬라이드로 옮길 때 글자를 무조건 축소하지 않는다. 축소 대신 View 분리
  또는 확대 경로를 제공한다.
- 용도별 하한(문서 11px 화면 기준 · 인쇄 5pt 실물 기준)을 지키기 어려우면 그 그림의
  밀도가 경고선을 넘은 것이다. 글자를 줄이지 않고 View를 나눈다.

## 밝기 대비 기준

색이 같아도 실제 배경이 다르면 읽힘은 다르다. 역할(글자·관계선·포커스 표시)별로
실제 놓이는 배경 위에서 WCAG 2.x 상대 휘도 대비를 검사한다. 같은 색이 글자에도
쓰이면 글자 기준을 적용한다.

기준:

- 본문 텍스트: 4.5:1
- 큰 텍스트(18pt 이상 또는 14pt 굵게): 3.0:1
- 의미 있는 비텍스트(관계선·상태선·강조 테두리·포커스 표시): 3.0:1
- 순수 장식(격자·구분선·배경 틴트): 기준 없음. 검사 결과에 참고 수치만 기록한다.
- 반투명 색(rgba, fill-opacity)은 배경과 합성한 뒤 계산한다.

검사 방법(렌더더 밝음·어두움 테마와 보고서 밝은 테마를 모두 검사):

```bash
python3 <skill>/scripts/verify_visual_contrast.py   --output-json qa/visual-contrast.json
```

이름 있는 공유 시각 프로필(D5 — 보고서와 그림이 같이 쓰는 색·글꼴·간격 역할 묶음)에도
같은 검사를 돌린다: `--profile <이름>`(예: `high-contrast`)을 주면 보고서 템플릿에 정의된
프로필 역할 값을 템플릿 기본값 위에 덮어쓴 상태로 같은 63역할을 검사한다. 고대비 프로필은
63역할 모두 통과(한계 기록 없음)다. 프로필의 빠진 역할은 기본값으로 보충되고, 템플릿에
없는 역할은 경고 후 무시된다. 인자 없이 실행하면 언제나 현재 템플릿 값(기본 프로필)을
검사한다.

### 한계 기록(기준 미달, 이중 표시로 유지)

아래는 기준 미달이지만 상태가 다른 신호로 이중 표시되어 기능이 유지되어 색을
바꾸지 않고 기록으로 남긴 항목이다. 검사기는 이들을 `[LIMIT]`·경고로 보고한다.
한계를 없애는 변경을 할 때는 이 목록과 검사기 note를 함께 갱신한다.

- 선택 플로우 버튼 테두리(accent-line) · 강조 배경 위 2.02/2.77 — 선택 상태가
  배경색(accent-soft)과 텍스트 색(accent)으로 이미 이중 표시된다. 테두리는 세 번째 보강이다.
- 조건 분기 선(warn-line) · 캔버스 위 2.21(밝음; 어두움 3.63 통과) — 조건 상태는
  범례, 사이드바 상태 태그 텍스트(warn-text 6.78/9.51), 점선 무늬와 함께 전달된다.
- 유령 관계선(edge 45% 합성) · 캔버스 위 1.65/1.65 — 도달 불가 상태의 의도적으로
  가라앉힌 흔적이다. 실선 구간(–stop 5.38/7.40)과 상태 칩·범례가 상태를 직접 전달한다.
  기본색 자체(RND-201)는 화살촉 폴백·범례에도 쓰여 3.0 이상을 유지한다.
- 순수 장식으로 분류한 항목(구분선·격자·상태 칩 테두리·표 테두리·하이라이트 틴트)은
  기준 없음 범주로 검사 결과에 수치만 기록한다.
- 보고서 템플릿은 밝은 테마만 제공하므로(`color-scheme: light`) 어두움 검사 대상이 아니다.
- 공유 시각 프로필(D5)은 화면(보고서·임베드 렌더더·전체 화면 다이어그랬로그)과 SVG
  내보내기에 적용된다. 미리 렌더링된 인쇄 이미지(printDataUri)는 빌드 시점 산출물이라
  프로필 반영이 안 된다 — 프로필을 바꾼 화면과 인쇄물이 다르게 보일 수 있다.

## 금지

- 과밀도를 해결하려고 글자를 읽을 수 없게 줄이기
- 서로 다른 추상화 수준을 한 장에 넣기
- 화살표를 생략해 관계 의미를 감추기
- 모든 기능을 첫 화면에 배치하기
- 색상만으로 확인됨·미확인·충돌 상태를 구분하기

## 접근성

- 색상 외에 텍스트·아이콘·선 스타일을 함께 사용한다.
- 다이어그램에 대체 텍스트와 caption을 둔다.
- 브라우저 확대와 키보드 탭 이동을 지원한다.
- 한글이 들어간 SVG는 실제 브라우저에서 깨짐과 잘림을 확인한다.
